Colour Palette

Warm near-black ground, parchment text, a single gold accent — and every border built from that same gold at reduced opacity. No true black, no true white, no grey anywhere in the system.

SOURCE OF TRUTH — :root IN index.html AND shop.html

Grounds

Two backgrounds alternate down the page to separate sections. Both are warm — brown-biased rather than neutral.

--ink

#0d0b08

Page background. The default ground everywhere.

--ink-soft

#1a1610

Alternating bands — About, Services, Formats, Catalog, Merch.

Text

Each row is set in the colour it describes. Contrast is measured against --ink; ratios on --ink-soft run roughly 8% lower.

--parchment #f0e8d5 Body copy and the hero title 16.11 · AAA
--cream #ede3cc Section titles and card headings 15.41 · AAA
--fog-light #d4c9b0 Note blocks — used once per page 11.96 · AAA
--fog #b8a88a Secondary text, nav links, descriptions 8.43 · AAA
--gold-dim #8a6525 Eyebrow labels, footer brand, rules 3.71 · AA LARGE

One thing to watch: --gold-dim clears AA for large text only, but it's currently used on eyebrow labels set at 0.65rem. Those sit below the AA threshold for body-size text. Fine for decorative labels whose words repeat elsewhere; worth nudging brighter if any of them ever carry information you can't get another way.

Accent

One accent, used everywhere it matters. The most-referenced token in the stylesheet — 18–19 uses per page.

--gold

#c9973a

Links, hovers, rules, ornaments, primary buttons, the numerals on service cards.

--gold-dim

#8a6525

The muted register of the same hue — labels and quiet ornament, where full gold would shout.

Borders

The detail that makes the site feel warm: borders aren't grey. They're --gold at 25% and 60% alpha, so they pick up whatever sits behind them.

Over --ink

--border · 25% → composites to #3c2e14

--border-strong · 60% → composites to #7e5f26

Over --ink-soft

--border · 25% → composites to #46361a

--border-strong · 60% → composites to #836329

--border is the standard hairline — section dividers, card edges, grid lines. --border-strong is reserved for hover states and ghost-button outlines.

Declared but unused

Two colours sit in :root with zero references on either page. Presumably intended as secondary accents and never wired up.

--rust

#8c3a1e

Burnt orange-red. 0 uses.

--moss

#2e4a2e

Deep desaturated green. 0 uses.

Both are too dark to carry text on these grounds (2.56 and 2.00 against --ink), so they'd work as fills or badges rather than type — a sold-out tag, a sale flag, category coding on the shop page. They're already in the right key if a second accent is ever needed.

The tokens 
:root {
  --ink:           #0d0b08;
  --ink-soft:      #1a1610;
  --parchment:     #f0e8d5;
  --cream:         #ede3cc;
  --gold:          #c9973a;
  --gold-dim:      #8a6525;
  --rust:          #8c3a1e;
  --moss:          #2e4a2e;
  --fog:           #b8a88a;
  --fog-light:     #d4c9b0;
  --border:        rgba(201,151,58,0.25);
  --border-strong: rgba(201,151,58,0.6);
}

This sheet is set in system serif and monospace. The site itself uses Cinzel for headings, IM Fell English for body and Space Mono for labels — those aren't loaded here, so treat this as a colour reference, not a type specimen.

Rendered dark-only on purpose: every value above is specified against a near-black ground, and showing them on white would misrepresent how they behave.
